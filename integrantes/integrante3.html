01 / REDES DE ÁREA LOCAL

Configuración de una red LAN con switches

Una red LAN (Local Area Network) permite conectar diferentes dispositivos dentro de un área limitada, como una oficina, un laboratorio o una institución educativa.

En esta práctica se diseñó una topología de red utilizando Cisco Packet Tracer, en la cual varios computadores se encuentran conectados a un switch central.

El switch permite que los dispositivos conectados intercambien información dentro de una misma red local, utilizando las direcciones MAC para reenviar las tramas.

Descripción de la topología

En la imagen se observa un switch Cisco 2960 conectado a varios computadores, distribuidos visualmente en tres grupos.

Cada grupo está identificado mediante un color diferente, lo que facilita la organización de los equipos dentro de la infraestructura.

Todos los computadores visibles están conectados al mismo switch central. Esta distribución corresponde a una topología física en estrella.

Conceptos aprendidos

  1. Red LAN

    Permite conectar computadores y otros dispositivos dentro de una misma área local.

  2. Switch

    Es un dispositivo de red que conecta equipos y reenvía tramas según las direcciones MAC.

  3. Topología en estrella

    Los dispositivos se conectan a un equipo central, facilitando la administración de las conexiones.

  4. Segmentación de redes

    Los equipos pueden organizarse en diferentes grupos o redes lógicas mediante VLAN, siempre que estas se configuren.

Conclusiones de la práctica

Esta práctica permite comprender la importancia del switch en una red de área local y cómo una topología en estrella facilita la conexión de múltiples computadores.

También permite identificar que la organización visual de los equipos no significa necesariamente que existan redes independientes. Para separar los grupos en diferentes redes lógicas sería necesario configurar VLAN.

Finalmente, se comprende que una infraestructura bien organizada facilita la identificación de dispositivos y la administración de la red.

02 / ENRUTAMIENTO ENTRE REDES

Interconexión de redes mediante routers

Un router es un dispositivo encargado de conectar diferentes redes y determinar por dónde deben viajar los paquetes para llegar a su destino.

En esta práctica se diseñó una infraestructura utilizando tres routers, tres switches y cuatro computadores, mediante Cisco Packet Tracer.

Los routers se encuentran conectados entre sí, mientras que cada uno proporciona conexión a una red local a través de un switch.

Descripción de la topología

En la imagen se observan tres routers conectados en una estructura lineal. Cada router está conectado a un switch Cisco 2960.

El primer switch conecta un computador, el segundo switch conecta otro computador y el tercer switch conecta dos computadores.

Esta estructura permite representar diferentes redes locales que pueden comunicarse entre sí mediante routers, siempre que el direccionamiento y las rutas estén correctamente configurados.

Conceptos aprendidos

  1. Router

    Dispositivo que conecta redes diferentes y permite el encaminamiento de paquetes IP.

  2. Direccionamiento IP

    Permite identificar dispositivos e interfaces dentro de una red, utilizando direcciones IP y máscaras de subred.

  3. Puerta de enlace

    Es la dirección del router utilizada por los computadores para enviar paquetes hacia otras redes.

  4. Enrutamiento

    Permite determinar las rutas que deben seguir los paquetes para llegar a redes remotas.

  5. Pruebas de conectividad

    Herramientas como ping permiten verificar si existe comunicación IP entre diferentes dispositivos.

Conclusiones de la práctica

Esta práctica permite comprender la diferencia entre un switch y un router. Mientras el switch conecta dispositivos dentro de una red local, el router permite la comunicación entre redes diferentes.

También se identifica la importancia de configurar correctamente las direcciones IP, las máscaras de subred, las puertas de enlace y las rutas de los routers.

La topología muestra cómo varias redes pueden interconectarse mediante dispositivos de enrutamiento. Sin embargo, para comprobar que la comunicación funciona correctamente, es necesario realizar pruebas de conectividad.

03 / CONCLUSIONES GENERALES

¿Qué aprendí de estas actividades?

Las prácticas realizadas en Cisco Packet Tracer permitieron comprender mejor cómo se construyen y organizan las redes de computadores.

Aprendí que los switches y los routers cumplen funciones diferentes, pero ambos son fundamentales para permitir la comunicación entre dispositivos.

También comprendí que el modelo OSI permite explicar el funcionamiento de las redes mediante diferentes capas, especialmente la capa de enlace de datos y la capa de red.

Finalmente, estas actividades permiten relacionar los conceptos teóricos con situaciones prácticas, facilitando la comprensión del direccionamiento IP, las topologías y la interconexión de redes.
